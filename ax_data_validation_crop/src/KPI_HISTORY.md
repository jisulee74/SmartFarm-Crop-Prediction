# AX 성능 목표 변경 이력 — 2026-10-27

이번 변경은 화면의 대표 집계와 내부 계획 목표 수정이며 모델·예측·선정 결과 변경이 아니다.

| 항목 | 이전 | 변경 후 |
|---|---|---|
| 대표 성능 | 화방별 지표 동일 가중 산술평균 | 선정 모델의 pooled Test; 다중 시드는 시드별 pooled 지표 평균·표본 표준편차 |
| 목표 범위 | 1·2·3화방 및 합계, 작물별4개·총8타깃 | 토마토1~20·딸기1~5화방 공통 모델 |
| AS-IS | 타깃별 Validation BEST | 발표자료 v3.1의 1시드 pooled Test 기준 고정 |
| 주 목표 | RMSE 10% 감소 | 같은 평가 사례에서 RMSE 5% 감소 |
| 토마토 과거 예시 | 0.2623 → 0.2361 | 범위가 달라 직접 비교 불가; 현 목표 0.47 → ≤0.44 |
| 변화구간 MAE | 15% 개선 참고 목표 | 현재 KPI에서 제외, 원본 기록 보존 |
| 보조 지표 | 과거 계획 혼재 | MAE·CCC 비열화 확인, R²는 RMSE 목표 연동 참고 |

과거 0.2623/0.2361은 토마토 **1화방**, 의미 통합 127조합 1시드 잠정 Validation BEST의 0.2622976061555551 및 그 90%인 0.23606784553999957을 반올림한 값이다. 현재 1~20화방 pooled Test와 비교하는 수치가 아니다. 전체 과거 표는 [보존 JSON](legacy_kpi_reference.json)에 담았다.

과거 근거 문서 `ax_data_validation/ax_direction/03_AsIs_ToBe_검증체계_KPI.md`는 10%를 초기 제안·기획용 계산으로 기술하고 계약상 절대 통과선으로 삼지 않는다고 명시한다. 이번 조사만으로 공식 사업 요구사항에 10%가 포함되어 있는지는 확인할 수 없다. 공식 협약·과업 기준에서의 요구 여부는 미확인이다.

현재 근거는 사용자 지정 발표자료 v3.1(2026-10-27) 7쪽이다. 7쪽은 RMSE 5%와 내부 목표임을 명시하지만, 같은 PDF 4쪽 하단에는 10% 문구가 남아 있다. 대시보드는 요청의 명시적 5% 및 7쪽을 적용한다. PDF 자체는 수정하지 않았다.

정식 결과가 게시되면 대표 성능만 해당 결과의 pooled 지표로 바뀐다. 이 목표표는 발표 당시 1시드 AS-IS를 계속 사용하며 자동 재산정하지 않는다. 기준 변경은 별도 검토·확인 대상이다. 표의 반올림값과 실제 계산 경계는 다를 수 있으므로 5% 감소·MAE·CCC 비열화는 반올림 전 값으로 확인한다.

기존 실험 산출물 `summary.json`과 그 aggregation 메타데이터는 보존한다. 화면 집계 정책은 `src/presentation.js`에서 별도로 적용하며 검증된 summary의 `pooled`를 읽는다. 데이터가 없거나 시드 구성·화면 버전이 불일치하면 산출 불가를 표시하고 화방평균으로 대체하지 않는다.
