1차 내부 계획 KPI는 동일 평가 대상·분할·시드에서 As-Is 대비 RMSE 10% 이상 감소입니다. As-Is는 방향·층수를 장치 의미로 통합한 127개 조합 전체 Validation 순위의 타깃별 최저값입니다. 현재 1시드 선별 기준값은 정식 추가 검증 완료 후 갱신하며, 신규 AX 데이터 비교 시 동일한 평가 조건으로 다시 고정합니다. MAE는 감소하고 R²·CCC는 하락하지 않는지도 함께 확인합니다. 변화구간 MAE는 최신 Test에서 현재값과 다음 조사값이 다른 행의 3시드 평균입니다. 미관측 현재값은 변화 구간에서 제외합니다. 15% 개선값은 Test 진단용 참고 목표이며, 신규 AX 데이터 비교 시 같은 코호트에서 재산정합니다. 현재값 유지 기준선은 미관측 행에 train 중앙값을 사용하고 0 예측 기준선과 함께 동일 평가 행에서 계산합니다.
