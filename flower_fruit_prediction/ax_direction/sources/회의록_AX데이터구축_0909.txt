                               회의 내용

1. 올해(3 차년도) AX 데이터 구축 범위 및 정의
- 올해 신규 구축분은 AX 데이터 관점으로 구축하며, 1·2 차년도(24·25 년) 데이터는 기존 생육조사 방식
 그대로 유지함.
- 기존 빅데이터 : 환경·제어·생육 중심의 ‘상태 데이터’ 위주로 수집된 데이터로 정의
- AX 데이터 : 상태·행동·맥락·제약·결과를 모두 포함하여 AI Ready 상태로 전환 가능한 데이터로 정의
- 추가 수집 대상 : 농작업(행동) 데이터, 맥락 데이터, 제약 데이터, 암묵지 데이터
- 맥락 데이터 수집 방식 : 구조화된 질문지 기반 인터뷰 -> 농업인이 해당 농작업을 수행한 이유를
 문답으로 확보 후 구조화
- 데이터 범위·항목을 발주처가 사전 지정하는 방식은 어려우며, 본 사업에서 검증 모델에 적합한 AX
 데이터셋을 정의해 나가는 것으로 정리함.



2. 1·2 차년도 데이터의 AI 모델 검증 결과
- 검증 대상 : 스마트팜코리아 축적 데이터 (기존 입력 변수 기준)
- 적용 알고리즘 : TFT 등 딥러닝·트랜스포머 계열 신규 알고리즘 (기존 통계·머신러닝 기반 모델과 구분)
- 결과 : 성능 지표가 수용 가능한 수준에 미달 (RMSE 1.48 수준, 목표 0.7 미달, MAE·CCC 특히 저조) -
 > 범용 모델로서의 성능은 입증되지 않음.
- 잠정 결론 : 현재까지 수집한 데이터만으로는 AI 모델 학습·구축에 한계가 있다고 판단함.
- 전제 : 확률통계·머신러닝 관점에서는 기존 데이터에 문제가 없으며, ‘AI 학습 데이터로서의 부적합’
 문제로 한정하여 정의하기로 함.



3. 검증 모델 범위 및 변수 정의 방식
- 자율제어 모델은 투입 인자가 과다하여 1 개 농가 데이터로 검증이 어렵다고 판단, 꽃수·착과수 예측
 모델 중심으로 범위를 축소하기로 기정의함.
- 착수보고 시 제안된 GEAS 모델 적용은 단계를 낮추어 순차적으로 확인해 나가기로 함.
- AI 모델 특성상 사전에 입력 변수를 특정하기 어려우며, 관련 변수를 최대한 투입한 뒤
 파인튜닝·파라미터 조정 과정에서 변수가 취사선택되는 방식임.
- 목표 성능 지표(Recall, F1-score 등)를 선설정하고 해당 수준 도달까지 반복 학습·조정 예정
- 현재 가설 : 맥락·제약 데이터를 추가 수집하여 AI 알고리즘을 학습시켰을 때 성능 지표가 개선될
 것임.



4. 1·2 차년도 데이터 원인 분석 및 가설 구체화 요청 (농정원 양종열 실장)
- 요청 1 : 꽃수·착과수 예측 모델 검증 결과에 대한 인사이트를 AI 전문가 관점에서 명확히 정리
  1. 성능 저하 원인이 데이터 추가 수집의 문제인지, 기존 데이터 간 연관성의 문제인지, 표본수
   부족의 문제인지 구분하여 리포트로 산출
  2. 4 개 성능 지표 관점에서 모델이 왜 낮게 나왔는지를 손에 잡히도록 구체화
- 요청 2 : 원인 분석을 토대로 올해 수행할 개선 과업(가설)을 실제 태스크 단위로 명확히 제시
  1. ‘행동·맥락·제약·결과 데이터를 모두 모아 학습시켜 해결하겠다’ 수준의 포괄적 정의로 갈음해서는
   안 됨.
  2. 어떤 데이터를 추가하여 어느 지표를 어느 수준까지 개선할 것인지 설명 가능해야 함.
- 데이터 가치 관점 : 1·2 차년도 데이터는 체계적으로 수집된 완결성 있는 데이터이며, 데이터 자체의
 문제로 정의해서는 안 됨.
- AX 데이터는 무에서 유를 만드는 것이 아니라 기존 데이터 베이스 위에 얹는 것이므로, 기존
 데이터를 부정하지 않는 방향으로 설명되어야 함.
- 데이터 개방 시 설명 논리 : 구축한 AX 데이터셋 -> 검증 모델 -> 지표 기반 성능 적합성 확인 순으로
 제시 가능해야 함.
- 개선 전·후(As-Is / To-Be) 비교가 명확히 드러나도록 한계 요인과 추가 구축 항목을 대응시켜 정리
 필요



5. 데이터 수집 방법론 검증 (PoC)
- 농정원 의견 : 재배사 심층 인터뷰로 과거 1 주일 농작업을 문답하는 방식은 농장주 기억에
 의존하므로 정확성 측면에서 회의적임.
- 더아이엠씨 수집 방식 : 인터뷰 단독이 아닌 영농일지(농장주 자체 기록) · CCTV 3 대 영상 · 방문
 문답을 종합하여 교차 확인
- 영상 데이터는 야간 구간을 제외하고 주간 유의미 구간 중심으로 정제·정사하며, 향후 AI 탐지 적용
 예정 (현재는 인력 정사)
- 방법론 확정 전 1~2 주 규모로 실제 수집을 수행하고, 산출된 구조화 데이터를 근거로
 적합성·한계·이슈를 재논의하기로 함.
- 맥락 데이터 수집 방법에 대한 상세 논의는 원인 분석 및 과업 정의가 완료된 이후 재논의하기로 함.



6. QR 기반 농작업 데이터 수집 방식 비교
- QR 방식 : 자기기입식이며 농작업 인력 관리 용도에서 출발 -> 문항 뎁스가 깊어질수록 정확한 응답
 확보가 어려움.
- 더아이엠씨 방식 : 일지·CCTV 등 근거 자료를 기반으로 조사자가 질문·기록 -> 포괄적·심층 문항에도
 양질의 데이터 확보 가능
- 양측 목적·방식이 상이하여 QR 방식만으로 맥락·제약 데이터를 구조화하기에는 한계가 있다고
 판단함.
7. 대상 농가 선정 및 관리
- 김해 농가 : 농장주가 일기 형식으로 당일 농작업을 기록 -> 데이터 교차 검증에 유리
- 나머지 농가의 기장(기록) 습관 보유 여부를 추가 확인 필요



8. 사업 확산 관점
- 내년 신규 사업 대부분이 AX 데이터 관점의 데이터 총조사 형태로 추진될 전망
- AX 데이터의 구조·수집 방식 및 농작업·맥락·제약 데이터에 대한 표준 논의가 예상되므로 본 사업의
 레퍼런스 확보가 중요함.
- 대외 설명 시 누가 보더라도 합리적인 논리 구조를 갖추도록 정리 필요

                         향후 일정 및 조치 예정

1. 1·2 차년도 데이터 한계 원인 분석 리포트(PPT) 작성 : 꽃수·착과수 예측 모델 검증 결과에 대해
표본수 부족·기존 데이터 간 연관성·추가 수집 필요성 등 원인을 구분하고, 성능 지표 관점의 한계를
구체적으로 정리


2. 올해 AX 데이터 구축 과업 구체화 : 원인 분석을 토대로 성능 개선 가설과 실제 수행 태스크를 항목
단위로 정의하고, 기존 데이터 대비 추가 구축 항목을 대응시켜 제시(AS-IS TO-BE 형식)
