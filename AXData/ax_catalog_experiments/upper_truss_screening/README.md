# 상위 화방 확장 1시드 간략실험

- 토마토: 동일 개체의 1~20화방 개화수. 딸기: 1~7화방 착과수.
- 화방별 별도 모델 27개 대신 작물별로 화방을 공유하는 공통 모델을 학습한다. 화방 번호를 입력하며 화방별 결과를 별도 제공한다.
- 시드 42, 작물 2 × 입력 4 × 모델 6 = Validation 48회. 모델별 Validation 우승 입력 12개만 Train+Validation 재학습 후 Test 1회씩, 최대 총 60회 학습.
- 모델: Poisson, Random Forest, CatBoost, MLP, TabM, TFT. 기존 공통 어댑터 재사용.
- 3-fold 튜닝·3시드 정식 검증은 수행하지 않는다. 기존 시설 Test를 이미 점검한 탐색적 실험이며 신규 외부 검증이 아니다.
- 현재값 유지·항상 0·학습 평균 기준선은 모델과 같은 평가 행에서 계산한다.

## 입력

A: 같은 화방의 현재값·과거 3회·변화·과거 최대·관측 횟수·최초 양수 관측 이후 경과일, 화방 번호, 작기 및 조사 경과일.
B: A + 같은 조사일의 인접 화방 값·유효 관측 화방 수·양수 화방 수·양수 위치 최저/최고·수량 가중 위치와 이전 조사 대비 이동·상대 화방 위치.
C: B + 현재 영양생장 값.
D: C + 기존 고정 데이터의 7일 환경·근권·장치 의미 통합 제어 집계, 수치 작기 정보.

딸기의 위치는 **착과가 관측되는 위치**이며 토마토와 같은 개화 이동 법칙을 강제하지 않는다. `observed_total`은 유효 관측 화방의 부분합이며 미관측 화방까지 포함한 총수량이 아니다. `observed_trusses`를 함께 후보로 제공한다.

외부 입력은 기존 선별 데이터의 같은 개체·작기·조사일에만 연결한다. 새로 환경 원천 전체를 재집계하지 않은 간략실험이다. 연결되지 않은 값은 결측을 유지하고 학습 중앙값으로만 대체한다. 데이터마다 연결률을 manifest에 기록한다. 외부 입력 가용성은 기존 데이터의 관측 범위에 영향을 받으므로 후속 정식 실험에서 전체 원천으로 재집계해야 한다.

학습시설 자료에서 결측률 50% 초과·상수 입력만 제외한다. 네 구성은 후보 수준에서 단계적으로 확장하며, 화방 번호·이력 정보가 과도한 상관/VIF 제거로 사라지지 않도록 이번 간략실험에서는 상관/VIF 제거를 수행하지 않는다. 학습에 맞춘 안정화 전처리(중앙값, 표준화·범위 제한)는 기존 어댑터를 재사용한다.

## 타깃과 누출 방지

원천의 시설·작기·개체·화방·날짜 중복 값 충돌은 결측으로 처리하고 원천 조사일 캘린더는 유지한다. 같은 화방의 다음 원천 조사일 값이 유효하며 현재값도 유효한 1~14일 간격 조사쌍을 사용한다. 목표가 없는 날짜를 먼저 삭제해 미래 날짜로 건너뛰지 않는다. 다음 조사까지의 실제 간격은 대상 정의·감사에만 사용하고 입력에는 넣지 않는다.

목표값·미래 조사일·시설 ID는 입력에서 제외한다. 첫 양수 관측일은 현재까지의 이력만 사용한다. 과거 최대는 예측 상한이 아니라 입력이다. 예측은 음수만 0으로 제한하며 상한은 두지 않는다.

시설 분할은 기존 실험과 동일하고 작물 내 모든 구성·모델이 같은 행을 사용한다. Validation의 pooled RMSE → MAE → 입력 수/구성명으로 모델별 조합을 선정하고 Test 이전에 동결한다. Test는 선정 epoch로 Train+Validation을 재학습한다. 모델 전체 최우수 역시 Validation에서 미리 동결하며 Test로 순위를 바꾸지 않는다.

기존 모델·대시보드·배포 파일은 수정하지 않는다.
