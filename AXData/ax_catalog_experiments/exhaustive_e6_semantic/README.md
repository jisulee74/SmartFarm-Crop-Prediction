# E6 의미 통합 v2

기존 `exhaustive_e1_e7_v1` 스냅숏과 결과를 읽기 전용으로 재사용하면서,
방향·창 층수를 통합한 E6 파생변수로 E6 포함 16개 조합만 다시 실행한다.

```bash
bash run_ax_e6_semantic.sh
```

같은 명령을 다시 실행하면 완료된 Run ID와 조합 요약을 건너뛰고 이어서 실행한다.
출력은 `ax_catalog_experiments/outputs/exhaustive_e6_semantic_v2/`에만 기록된다.

준비 단계는 v1 스냅숏·타깃 행 해시, 고정 코드 정의, 미등록·중복 코드,
단위 충돌, 타깃별 세 시간순 CV 구간의 E6 가용성을 학습 전에 검사한다.

`E6S__장치군__측정유형__기간__통계` 형식의 변수만 E6 v2에 들어간다.
기록이 없는 구간의 측정값은 결측으로 유지하고, 기록 장치 수만 0으로 기록한다.
