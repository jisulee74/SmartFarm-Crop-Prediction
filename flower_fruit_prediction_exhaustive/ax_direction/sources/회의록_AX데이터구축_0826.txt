                                회의 내용

1. 회의 목적 및 추진 방향 공유
- 목적 : 농업분야에 기존에 존재하지 않는 AX 데이터셋을 구축하는 사업으로, 본 구축 결과가 향후 AX
 데이터셋 구축의 선도적 시범사례가 될 것으로 판단됨. 수행사와 농정원이 구축 방향을 공유하고
 성공적인 결과물 도출을 위해 소통하는 자리
- 전제 : AI 가 데이터 구조를 이해하고 학습·추론·검증까지 수행할 수 있는 형태로 구조를 설계하는 것
- 쟁점 : AX 데이터가 없는 것인지 모델이 없는 것인지 -> 실제로는 양측 모두 부재함. AX 데이터
 구축과 함께 검증 체계 마련이 필요하며, 모델이 없더라도 데이터 자체를 검증 필요
- 연말 목표 : 농정원 스마트농업실·정보전략실 협업을 통한 국내 최초 AX 데이터셋 구축 및 암묵지
 데이터 기록 사례를 우수농가 스토리라인으로 공개하는 것을 목표로 함.



2. 암묵지 데이터의 정의 및 범위 (농정원 김지훈 본부장)
- 원칙 : 다룰 수 없는 암묵지는 암묵지가 아님. 단순화하여 우리가 관리할 수 있는 범위만 암묵지로
 정의함.
- 정의 : 어떤 조건에서 무엇을 했는지에 대한 ‘기록’ -> 농작업·수확·경영 영역의 기록이 핵심이며,
 기온·제어 상태·가격 등 그날의 조건 데이터는 별도 수집되므로 두 축을 결합하면 원인과 결과를 모두
 갖춘 데이터셋이 됨.
- 범위 : 제어 정보·생육 정보는 기존 수집 체계로 확보 가능 -> 현재 빠져 있는 농작업·수확·경영을 보완
 대상으로 함.
- 제어 의도 : 자율제어와 사람의 의도적 제어를 구분하고, 환경 설정 변경 시점과 그 의도(사유)를 기록
 항목에 반드시 포함
- 원인과 결과에 해당하는 세트를 모두 갖추어 두고 필요시 활용할 수 있도록 구성하는 것이 목적임.



3. AX 데이터 구축 가이드라인 수립 현황 (더아이엠씨 전채남 대표)
- 현황 : 착수보고 이후 6 월부터 3 개월간 구축 가이드라인 수립에 집중, 현재 버전 1.0 수준 (약
 150 페이지 책자, 추후 공유)
- 데이터 수집·연계 표준 : 스마트농업 기자재 표준 설치 위치·각도 기준 정립, AI 레디 데이터 수집을
 위한 연계 체계 구축, 시설·작기 단위 식별체계 및 메타데이터 기록 기준 정리
- 이미지 AX 데이터 구축 : 촬영 거리·각도·해상도·조도 기준의 수집 가이드라인 및 라벨링 기준 마련.
 생리 진단·병해충 분류·성숙도 판단 3 종 AI 모델을 통한 검증 계획 수립. 현재 단일 시점 RGB 중심 ->
 향후 다시점·뎁스·멀티모달 확대 염두
- 암묵지 AX 데이터 구축 : 암묵지 정의 -> 현장 방문 시나리오 작성 -> 1 문 1 답 질문지 설계 순으로
 진행. 현장에서는 자연스러운 대화(인터뷰형)를 녹음하고, 이후 기록하여 정형 데이터와 시점을
 일치시키는 방식
- 이상치 탐지 AI 모델 : TranAD 모델 적용을 잠정 결론으로 함. 상주 스마트팜 실증단지 데이터 및
 2024~2025 년 우수농가 사업 수집 데이터로 검증하여 모델 성능을 확인함.
- 데이터 구조 3 원칙 : 측정의 표준화, 농가·시간을 키 값으로 한 데이터 연속성·연결성 확보, AI 레디
 데이터 관점의 활용 가능성



4. 암묵지 데이터 수집 방식 및 비교군 설정
- 현행 계획 : 전문 재배사가 주 1 회 방문하여 지난 일주일간의 농작업 내용·수행 사유·결과, 수확 및
 출하량, 등급·가격 등을 인터뷰로 수집. AX 데이터 수집 5 개 농가 중 4 개 농가는 전문 재배사가, 김해
 파프리카 농가는 더아이엠씨에서 직접 방문·수집
- 검토 의견 : 주 1 회 수집으로는 누락 가능성이 있음 -> 상주(매일) · 주 1 회 · 일반 생육조사 : 총 3 개
 비교군으로 구성하여 결과를 비교하고 적정 수집 주기를 도출할 필요
- 보완 방안 : AX 데이터 수집 온실 5 개소에 CCTV 및 농작업 수집용 카메라를 설치하여 농작업·생육
 상태를 상시 촬영. 해당 5 개 농가는 밀착 관리 대상으로 운영
- 수용성 : 농업인이 상시 기록에 익숙하지 않고 방문·기록을 부담스러워하는 점을 고려하여, 정보
 수집에 대한 거부감 해소 방안 마련 필요



5. 농정원 정보전략실 - 농업 ON 협업 및 QR 기반 농작업 수집
- 배경 : 정보전략실에서도 농작업 데이터 수집 체계를 구축 중 -> 별도 추진 시 향후 데이터
 통합·연계에 한계가 있으므로 기준과 체계를 함께 정리할 필요
- 수집 방식 : 정보전략실은 QR 방식, 당사는 음성 인식 기반 수집(작업 사유·맥락 포함)
- 원칙 : AX 데이터 수집 5 개 농가는 양측 대상 농가를 일치시키고, 예산을 공동 투입하여 농가 유인
 요인(보상)을 마련하기로 함.
- QR 적용 : 품목별 표준 농작업은 QR 로 수집 가능하도록 반영하고, 기존 구축된 QR 솔루션을 활용
- 질문 항목 : 암묵지 수집 질문지(농작업·수확·병해충 등)를 조속히 상호 공유하여 표준화 진행 필요
- 암묵지 카테고리(안) 8 종 : 환경 조치, 양액·관수, 농작업, 병해충, 생리 관찰·생육, 외부 요인,
 출하·경영, 제약 요건(에너지 등)
- 기본 정보(시설·작기 정의) 및 표준 농작업 정의가 양측 간 상이할 수 있으므로 상호 대조 후 정합화
 필요
- 참고 : 아이오크롭스(iocrops) 서비스에 유사 개념이 구현되어 있어 참고 필요
- 항목 연계 : 정보전략실이 농진청 표준을 반영하여 정의·보유 중인 농작업 항목 29 종(경영장부 기반)
 중 5 개 품목 해당 항목을 공유받아 그대로 준용하고, 중복 정의는 배제하기로 함.
- 역할 분담 : 경영 항목은 회계 관점으로 결이 달라 정보전략실에서 관리하고, 당사 수집 범위는
 출하량·상품등급·투입 인원 수준으로 한정
 - 도입 시기 : QR 서비스 도입 시점이 미확정이므로 우선 동일 항목을 수기 형태로 수집 -> 이후 QR·앱
  체계 도입 시 전환. 서비스 흐름 및 솔루션 활용 방식은 정보전략실에서 검토
 - 맥락 데이터는 농가별 특성 편차가 커 QR 로 수집하기 어려움 -> 온실 형태·지역·재식 주수 등 기본
  정보와 연계하여 농가 특성을 명확히 정의할 필요



6. AX 데이터 활용 모델 체계
 - 당사 계획 : 생육 상태 분석 모델, 화방수·착과수 예측 모델 2 종을 우선 활용하고 궁극적으로 AI
  자율제어 모델(더아이엠씨 사업)까지 3 종을 염두에 두고 데이터 수집
 - 검토 의견 : 착과수 예측 -> 추천 -> 결과 검증 -> AI 자율제어 순의 단계별(스텝 바이 스텝) 구성
  필요
 - 생산량 예측 모델은 신뢰성 확보를 위해 착과수·엽면적·과실 수 결과를 확인한 후 단계적으로 추진             메모 포함[오전1]: 서연씨 질문
 - 경영 진단 모델(투입 비용·자금 계획 등)에 대한 농가 수요가 높으므로 향후 검토 필요



7. 꽃수 및 착과수 예측 모델 검증 결과 및 한계
 - 지적 : R² 값이 0.1 수준으로 제시되었으며, 이는 상관관계가 성립한다고 보기 어려운 수준임 -> 산출
  오류 여부를 재확인하기로 함.
 - 지적 : 화방수는 적화·적과 등 이후 변수가 많아 수확량에 결정적이지 않음 -> 시작 지표로서의
  활용은 가능하나 예측 대상 설정 시 고려 필요
 - 방향 : 기존 빅데이터(스마트팜코리아 플랫폼 데이터) 기반의 모델 적합도 검증은 중단하고, 제한된
  AX 데이터셋이 투입되었을 때 작동하는 모델을 검증하는 데 집중하기로 함.
 - 검증 신뢰성 : 해당 모델이 AX 데이터의 검증 기준이 되는 만큼 기준 자체의 정확성 확보가 중요함 ->
  TTA 등 외부 모델 검증 수검 의향 확인 필요. 다만 AI 모델 분야의 검증 경험 부족으로 실효성이
  낮다는 의견도 제시됨.

8. AX 데이터셋 구성 요소 및 스키마 정의
 - 구성 요소 : AX 데이터는 상태 · 행동 · 맥락 · 제약 · 결과 5 개 요소로 구성됨. 상태(환경)는 센서,
  생육은 생육조사원, 행동·맥락·결과는 암묵지 인터뷰로 수집 주체를 구분
 - 요청 : 5 개 구성 요소별 데이터 항목을 스키마(데이터 정의서) 형태로 정리하여 공유 -> 필드 구성,
  데이터 형식·타입까지 확인 가능한 수준으로 작성
 - 피처·라벨 구조 : 상태·행동은 피처, 경영·결과·맥락·제약은 라벨 성격으로 구분되며, AI 가 읽고
  학습·추론·검증할 수 있는 AI 레디 데이터 구조로 설계 필요



9. 맥락 데이터의 정의 및 수집 방식
 - 정의 : 복합환경제어기의 기본 설정값대로 운영하지 않고 농장주가 수동으로 판단·개입한 ‘의사결정
  데이터’ 및 그 사유로 정의하기로 함.
 - 예시 : 습도가 높아 원칙상 천창을 열어야 하나 강우 시에는 천창을 열지 않고 유동팬으로 습도를
  조절, 고온에도 전력 비용을 고려하여 냉방기를 가동하지 않음 등
 - 수집 절차 : 상태·제어 데이터 로그 분석 -> 기본 설정값에서 이탈한 특이 시점 탐지 -> 해당 시점에
  한정하여 사유 질의 -> 텍스트 데이터로 구조화 (‘습하다’·‘꿉꿉하다’ 등 지역별 표현 편차는 단어
  클러스터링·표준화로 정제)
 - 한계 : 주 1 회 인터뷰만으로는 농장주의 기억에 의존하게 되어 데이터 신뢰성 확보가 어려움 -> 대외
  설명 시에도 신뢰도가 떨어질 수 있으므로 수집 방법 재검토 필요
 - 보완(안) : 농장주가 육하원칙(언제·무엇을·얼마나·왜·어디서·그 결과)에 따라 매일 음성으로 기록 ->
  조사원이 매일 확인·정리하여 주 단위 리포트 작성 -> 농장주 음성 기록 · 로그 기반 의사결정 ·
  재배사 현장 관찰 3 자를 교차 검증하여 암묵지 레퍼런스를 구축하는 방식
 - 주기 : 암묵지 데이터의 생성 주기는 최소 1 일 단위로 맞추기로 함. (경영일지 작성 주기 기준)
 - 인센티브 : 매일 기록에 대한 농가 보상 방안 마련 필요. 정리된 결과를 연 단위 리포트로 농가에
  제공하여 참여 유인 확보
 - 요청 : 5 개 농가의 1 주일치 로그를 활용하여 설정값 이탈 의사결정의 발생 빈도·유형(온도·습도·양액
  등)·발생 시점을 사전 시뮬레이션한 후 공유 -> PoC 성격의 개념 검증 선행 필요
 - 질문지 : 현행 8 개 영역 약 130 개 문항으로 과다함 -> 김해 파프리카 농가 선행 테스트 및 조사요원
  모의실습을 거쳐 필수·충분 항목으로 보완



10. 제약 데이터의 정의
 - 정의 : AI 모델이 산출한 행위가 정상적으로 실행되지 못하도록 제한을 가하는 요소 -> 구동기
  미설치, CO2 발생기 가스 미충전, 정전·인터넷 단절, 수확 인력 부족(5 명 필요 시 3 명 투입), 관수
  용수 부족 등
 - 영향 : 수확 시기 지연 -> 품위 등급·출하 가격 하락 등 결과 데이터에 영향을 미치는 요인으로 축적
 - 쟁점 : 온실 기본 정보(메타데이터)와 중복 소지가 있고 데이터 항목·수집 방식이 불명확함 -> 필드
  단위 정의 및 관리 필요성에 대한 추가 검토 필요
 - 방향 : 현재는 원론적·교과서적 수준의 정의이므로 농업 현장에 맞게 변형·보완하여 재정리하기로 함.



11. 경영·결과 데이터 수집 범위
 - 현행 : 조사 요원 배치를 통해 주 단위로 생산량 · 출하량 · 경매시장 품위등급 · 가격을 조사하여
  수입까지 산출 (기존에는 연 1 회 문답 방식)
 - 한계 : 에너지비·양액비·인건비 등 투입비는 조사 대상에서 제외되어 투입비 대비 생산성 판단이
  어려움 -> 정보전략실측과 역할 분담 검토 필요



12. 이미지 AX 데이터 검증 기준 및 자율제어 모델
 - 이미지 학습데이터는 AI 허브 ‘AI 학습데이터 구축 가이드라인’을 준수하여 구축할 것 -> 향후 AI 허브
  연계 고려
 - 성능 지표(F1 스코어 등) 및 검증 방식을 농정원과 사전 협의하고, 가능한 경우 외부 검증 수행. 자체
  검증 시에도 AI 학습데이터 통과 기준에 부합하도록 진행
 - 규모 : 이미지 30 만 장 촬영, 3 만 장 라벨링 (60 개 농가 생육조사 요원이 촬영, AX 데이터 수집 5 개
  농가 포함)
13. 전문 재배사 운영 및 현장 검증 계획
 - 현황 : AX 데이터 수집 농가 선정 완료, 전문 재배사 채용 절차 착수
 - 인력 : 현재 농사를 짓고 있는 인력을 우선 시하여 조사 요원으로서의 자격·역량을 갖춘 인력을
 지역별 파트타임으로 선발 -> 비용 및 현장 접근성 확보. 생육조사 요원과는 중복되지 않음.
- 사전 검증 : 김해 파프리카 농가에서 더아이엠씨가 직접 테스트 -> 조사 요원 선정 후 1:1 모의실습
 실시 -> 현장 적용 과정에서 도출되는 개선 사항을 반영하여 가이드라인을 지속 보완하고, 사업 종료
 시점에 프로토타입 수준의 암묵지 수집 가이드라인 완성을 목표로 함.
